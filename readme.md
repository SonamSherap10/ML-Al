## 📖 My Learning Methodology

I follow a concept-first and implementation-driven learning approach.

For every algorithm, I aim to understand:

1. **Problem:** What problem does the algorithm solve?
2. **Intuition:** Why does the algorithm work?
3. **Internal Working:** What happens behind the scenes?
4. **Mathematics:** What mathematical concepts power it?
5. **Training:** How does the algorithm learn from data?
6. **Prediction:** How does it make predictions?
7. **Implementation:** How can it be implemented using Python and Scikit-learn?
8. **Evaluation:** How do we measure its performance?
9. **Limitations:** When should we or shouldn't we use it?

My focus is on understanding the underlying mechanisms rather than blindly relying on libraries.
